# Commit message

1. Run `git diff --staged` and `git status`.
2. Write the subject as `type(scope): summary` (feat, fix, test, docs, refactor, chore), under 72 characters.
3. Add a body of up to three bullets explaining why, not what.
4. Mention the ticket id (for example `TICKET-102`) if the change came from one.
5. Show me the message; only commit if I say so.
